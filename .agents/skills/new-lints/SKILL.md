# New Lints

Using linear mcp, create a new Linter Rule issue for the `TOOLS-*` project in
FineDesigns workspace.

- title format should be `[lint] hyphen-case-lint-name` (see existing issues
  for examples)
- description should be ~1-2 sentences MAX; do NOT add fluff words, or add
  details unless the user asked you to
- add `lints` label, add to bottom of Backlog
